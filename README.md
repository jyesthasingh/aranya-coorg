# Aranya Coorg – Boutique Hotel of the Future

Website for the **MBA Digital Business Challenge 2026** (AI & Data-Driven Product Management).

Aranya is an 18-room boutique hotel inside a coffee estate in Coorg, Karnataka. The website is built to acquire guests, take direct bookings and show management the KPIs behind the business.

## What's on the site
| Section | What it does |
|---|---|
| Hero + availability search | Dates and guests, direct-booking offer |
| Rooms | 4 room types, scarcity badges, weekend dynamic pricing |
| Virtual tour | Drag-to-look-around tour of 5 spaces |
| AI Trip Designer | 4-question quiz → recommended room + experiences + package price |
| Experiences | Local add-ons that flow into the booking |
| Booking flow | Live price breakdown, GST, promo codes (`MBA2026`, `CIRCLE5`), confirmation + "what happens next" |
| Aranya Circle | 3-tier loyalty programme with sign-up |
| Reviews | AI review summary and aspect scores |
| AI Concierge chatbot | Answers rates, travel, policies; opens booking; hands off to humans |
| Boardroom | All 10 challenge dimensions + live KPI dashboard (occupancy, ADR, RevPAR, conversion, funnel, channel mix, AI engagement) |

## Publish on GitHub Pages (5 minutes)
1. Sign in at github.com → **New repository** → name it `aranya-coorg` → set **Public** → Create.
2. Click **uploading an existing file**, drag in `index.html` and `README.md`, then **Commit changes**.
3. Go to **Settings → Pages** → under *Branch* choose `main` and `/ (root)` → **Save**.
4. Wait 1–2 minutes. Your site is live at `https://<your-username>.github.io/aranya-coorg/`.

## Demo tips for the boardroom presentation
- Before presenting, open the Boardroom section and click **Load sample month** so the dashboard is full.
- Live demo: run the AI Trip Designer → *Book this package* → pay (demo) → show the booking appear in the KPIs.
- Ask the chatbot "Plan a romantic weekend" and "How do I reach Aranya?".

*Payments, emails and WhatsApp messages are simulated for this concept site. Data is stored only in the viewer's browser.*
